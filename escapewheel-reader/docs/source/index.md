# Escapewheel Reader

Tools to read escapewheel packets

## Installation

```bash
pip install escapewheel-reader
```

For development:
```bash
git clone https://github.com/AllenNeuralDynamics/escapewheel-reader.git
cd escapewheel-reader
uv sync
```

## Quick Start

```python
import escapewheel_reader

# Your code here
```
