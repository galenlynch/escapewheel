# Escapewheel Validator

Tools to validate escapewheel packets

## Installation

```bash
pip install escapewheel-validator
```

For development:
```bash
git clone https://github.com/AllenNeuralDynamics/escapewheel-validator.git
cd escapewheel-validator
uv sync
```

## Quick Start

```python
import escapewheel_validator

# Your code here
```
