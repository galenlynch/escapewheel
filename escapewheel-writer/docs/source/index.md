# Escapewheel Writer

Tools to write escapewheel packets

## Installation

```bash
pip install escapewheel-writer
```

For development:
```bash
git clone https://github.com/AllenNeuralDynamics/escapewheel-writer.git
cd escapewheel-writer
uv sync
```

## Quick Start

```python
import escapewheel_writer

# Your code here
```
