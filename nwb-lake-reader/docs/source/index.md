# NWB Lake Reader

Tools to read NWB lakes

## Installation

```bash
pip install nwb-lake-reader
```

For development:
```bash
git clone https://github.com/AllenNeuralDynamics/nwb-lake-reader.git
cd nwb-lake-reader
uv sync
```
