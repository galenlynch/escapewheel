# NWB Lake Validator

Tools to validate NWB lakes

## Installation

```bash
pip install nwb-lake-validator
```

For development:
```bash
git clone https://github.com/AllenNeuralDynamics/nwb-lake-validator.git
cd nwb-lake-validator
uv sync
```

## Quick Start

```python
import nwb_lake_validator

# Your code here
```
