# NWB Lake Writer

Tools to write NWB lakes

## Installation

```bash
pip install nwb-lake-writer
```

For development:
```bash
git clone https://github.com/AllenNeuralDynamics/nwb-lake-writer.git
cd nwb-lake-writer
uv sync
```
