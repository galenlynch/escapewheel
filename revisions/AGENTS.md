# Agent instructions for specification changes

The root `AGENTS.md` also applies. Before working here, read `CONTRIBUTING.md` in full and consult
the current generated v0.2 parts that the change would affect.

- Start uncertain or exploratory work as a proposal. Promote it to a draft only after its problem,
  scope, and intended direction are understood.
- Only the user may authorize acceptance. Do not assign an `R<N>`, mark a document accepted, or
  incorporate it into v0.2 without that direction.
- Never cite an agent instruction file from a proposal, draft, revision, or specification part.
- Apply the root authority model; do not treat a proposal, draft, accepted revision, or the frozen
  POC as an override.
