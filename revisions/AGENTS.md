# Agent instructions for specification changes

The root `AGENTS.md` also applies. Before working here, read `CONTRIBUTING.md` in full and consult
the current generated v0.2 parts that the change would affect.

- Start a change as an Open change document under `changes/`. Make it Ready only after its
  questions are answered and its Decision is written.
- Before requesting acceptance of a Ready change, critically appraise it and report the findings.
- Only the user may authorize acceptance. Do not assign an `R<N>`, mark a document accepted, or
  incorporate it into v0.2 without that direction.
- Never cite an agent instruction file from a change document, revision, or specification part.
- Apply the root authority model; do not treat a change document, accepted revision, or the frozen
  POC as an override.
