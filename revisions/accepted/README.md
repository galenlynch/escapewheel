# Accepted revisions

This directory contains numbered records of decisions incorporated into the generated v0.2
specification or the revision process. Read them for rationale, evidence, alternatives, and
provenance. Read the generated specification for the current packet contract and
`../CONTRIBUTING.md` for current process rules.

An `R<N>` number records incorporation order. It does not make this directory an independent or
higher-precedence source of normative requirements.
